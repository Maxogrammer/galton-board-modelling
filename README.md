# Galton Board 2D Physics Simulation (OpenMP)

Высокопроизводительная двумерная физическая симуляция доски Гальтона на C++20 с визуализацией на SFML на выборке до $10^6$ частиц.

---

## Ключевые инженерные решения

### 1. Пространственная оптимизация коллизий (Hexagonal Spatial Grid)
- **Проблема:** Прямой перебор столкновений $N$ активных шариков с $M$ препятствиями дает квадратичную вычислительную сложность $O(N \cdot M)$, что приводит к падению производительности при $N > 1000$.
- **Решение:** Пространство препятствий разбито на виртуальную гексагональную сетку с шагом, равным шагу расположения штырьков (`PIN_H_SPACING = 5.0`, `PIN_V_SPACING = 5.0`).
- **Результат:** Координаты шарика проецируются в индекс ячейки сетки за $O(1)$. Проверка коллизий выполняется только с ближайшими соседями ячейки, снижая вычислительную сложность обнаружения коллизий до линейной $O(N)$.

### 2. Физический движок и численное интегрирование
- **Фиксированный временной шаг:** Интегрирование уравнений движения выполняется с фиксированным квантом времени (`FIXED_TIMESTEP = 0.001 с`), что гарантирует независимость физики от частоты кадров рендеринга и исключает артефакты туннелирования частиц сквозь препятствия.
- **Импульсная модель коллизий:** Моделирование упруго-вязкого соударения с коэффициентом сохранения импульса (`LOSS_COEFF = 0.9`):
  $$v_{normal} = -(v \cdot n) \cdot n$$
  $$v_{new} = v + 2 \cdot v_{normal} \cdot k_{loss}$$
- **Разрешение проблем коллизии:** Геометрическая компенсация взаимного проникновения твердых тел путем смещения частицы вдоль вектора нормали столкновения на глубину перекрытия.

### 3. Многопоточность и масштабируемость (OpenMP)
- Физический пересчет движения и коллизий пула частиц распараллелен средствами **OpenMP** (`#pragma omp parallel for`).
- Применено динамическое планирование потоков `schedule(dynamic, 256)` для эффективной балансировки нагрузки на ядра процессора при неравномерном распределении частиц по высоте доски.
- Регистрация попадания частиц в нижние накопительные корзины синхронизирована через атомарные операции (`#pragma omp atomic`).

## Сборка и запуск

### Требования:
- ОС: Windows 10/11 (x64)
- IDE: Visual Studio 2022 (v143 toolset) с поддержкой C++20 и OpenMP

### Быстрый старт:
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Maxogrammer/galton-board-modelling.git
   ```
2. Открыть `GaltonBoard.sln` в Visual Studio 2022.
3. Выбрать конфигурацию **Release | x64**.
4. Запустить сборку и выполнение (**Ctrl + F5**). 
*(Необходимые DLL-библиотеки SFML уже находятся рядом с проектом).*
